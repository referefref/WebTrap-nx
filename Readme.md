# WebTrap-nx

WebTrap-nx is a Python 3 port of WebTrap 1.0.1 (March 2018), which was written for Python 2 on Ubuntu 16.04. The original introduction and usage follow below; the commands are the same, with `python3` in place of `python`.

## Changes from the original

* Python 3: `http.server` and `socketserver` instead of `SimpleHTTPServer` and `SocketServer`, `urllib.parse` instead of `urlparse`, `print()`, `range`, `dict.items()`, and bytes handling for hashing, templates and POST data.
* Web Cloner uses WebKit2GTK+ API 4.1 (or 4.0); API 3.0 no longer exists in current distributions. It needs a display, so on a server run it under `xvfb-run -a`. Debian 12 packages: `python3-gi python3-gi-cairo python3-requests gir1.2-gtk-3.0 gir1.2-webkit2-4.1 xvfb xauth`.
* The redirect template and `session.js` are found next to the scripts, so the cloner can be run from any directory, and `session.js` is copied into the output directory (the injected client-side code loads `/session.js`).
* Links relative to the cloned page's own directory (for example `js/app.js?v=1`) are rewritten as well as root-relative ones, so pages that use relative links no longer clone to a page with missing scripts and styles.
* Trap server: POST data containing `%` (for example the URL-encoded `first_session` cookie set by `session.js`) no longer raises an exception before the request is logged; a POST without a valid `Content-Length` is treated as an empty body; the listening socket can be reused immediately after a restart.

# WebTrap
This project is designed to create deceptive webpages to deceive and redirect attackers away from real websites.
The deceptive webpages are generated by cloning real websites, specifically their login pages.
For further reading material on the tool development, please visit our [blog](https://blog.illusivenetworks.com/phishing-the-phishers-using-attackers-own-tools-to-combat-apt-style-attacks).

## Getting Started
The project is composed of two tools:
* Web Cloner - Responsible for cloning real websites and creating the deceptive web pag.e
* Deceptive Web server - Responsible for serving the cloned webpages, and reporting to a syslog server upon requests

## Operating System
The original project was designed and tested on an Ubuntu 16.04 machine. WebTrap-nx was tested on Debian 12 with Python 3.11 and WebKit2GTK+ 2.50.

## Prerequisites
```
pip install requests
apt install python3-requests python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-webkit2-4.1 xvfb xauth
```

## How to use
### How to use the Web Cloner
```
usage: WebCloner.py [-h] [-o OUTPUT_DIRECTORY] website_url

positional arguments:
  website_url           The URL path to the web page you desire to clone

optional arguments:
  -h, --help            show this help message and exit
  -o OUTPUT_DIRECTORY, --output-directory OUTPUT_DIRECTORY
                        Setting the output directory for the cloned webpage
```
### How to run the Deceptive web server
```
usage: TrapServer.py [-h] [--webroot-directory WEBROOT_DIRECTORY]
                     [--syslog-server SYSLOG_SERVER]
                     [--log-file-path LOG_FILE_PATH]

optional arguments:
  -h, --help            show this help message and exit
  --webroot-directory WEBROOT_DIRECTORY, -d WEBROOT_DIRECTORY
                        root directory for the HTTP server
  --syslog-server SYSLOG_SERVER, -s SYSLOG_SERVER
                        syslog server that the deceptive user will report the
                        request to it
  --log-file-path LOG_FILE_PATH, -l LOG_FILE_PATH
                        access log file path
```
## Examples
### Cloning Wikipedia login page
```
xvfb-run -a python3 ./WebCloner.py -o ~/WikiPediaLoginPage/ https://en.wikipedia.org/w/index.php?title=Special:UserLogin
```
### Running deceptive web server
```
sudo python3 ./TrapServer.py -d ~/WikiPediaLoginPage/ -s <SYSLOG_SERVER>
```
